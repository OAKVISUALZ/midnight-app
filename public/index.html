midnight-app

A zero-knowledge message store deployed on the Midnight Network. Messages are sanitized via a native witness, validated in-circuit, and stored on-chain — all under a privacy-preserving ZK proof.

Sanitize Witness

Whitespace trimming runs natively via a TypeScript witness, avoiding inefficient in-circuit string operations.

Length Validation

Messages are enforced to be at most 100 characters inside the zero-knowledge circuit.

Local Devnet

Bundle your own devnet (node, indexer, proof-server) via included docker-compose.yml.

Multi-Network

Deploy to local devnet, Preview, or Preprod testnets with a single flag.

Smart Contract

The Compact contract exposes a single public ledger field and one circuit.

pragma language_version >= 0.23;

import CompactStandardLibrary;

export ledger message: Opaque<"string">;

witness sanitizeMessage(raw: Opaque<"string">): Opaque<"string">;

export circuit storeMessage(raw: Opaque<"string">): [] {
    const clean: Opaque<"string"> = sanitizeMessage(raw);
    message = disclose(clean);
}

Architecture

The sanitizeMessage witness is implemented in TypeScript and injected at deployment time. The circuit calls the witness, sanitizes the message (trimming whitespace and rejecting anything over 100 characters), and commits the result to the ledger via disclose. This keeps string manipulation out of the circuit while keeping the stored value disclosure-controlled.
